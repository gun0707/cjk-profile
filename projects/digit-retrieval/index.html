手写数字相似图片检索

输入一张手写数字图片，从测试集剩余的 269 张图中找出最相似的五张。这个 CPU 实验沿用分类实验训练的 PyTorch 模型。

从分类到检索

原来的分类实验输出 0 到 9 的类别分数。检索时，跳过分类层，取 ReLU 后的 64 维特征，计算查询图与每张候选图的余弦相似度并排序。程序排除查询图本身，数字标签用于核对结果。

一次实际运行的结果

用测试集第 0 张图查询，标签为 6。前五张的标签都为 6。

  1. 第 6 张，相似度 0.9843
  2. 第 191 张，相似度 0.9744
  3. 第 52 张，相似度 0.9698
  4. 第 180 张，相似度 0.9694
  5. 第 62 张，相似度 0.9686

这组排序来自固定测试划分的一张查询图。后续可以在同一候选库上比较像素和隐藏层特征，并用全部查询的 Top-1 同类命中率评价结果。

在本地复现

下载或克隆仓库，切换到 projects/digit-retrieval。用装有项目依赖的 Python 运行以下命令。首次运行会自动训练默认模型。

python retrieve.py
python retrieve.py --query-index 12
